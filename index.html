Smart Education — Admin

এই lightweight admin starter-এ Data folder-এর JSON files manage করার নির্দেশনা রাখা হয়েছে।

How to add a new Model Set

  1. একটি নতুন JSON file তৈরি করুন।
  2. সঠিক class/subject folder-এ রাখুন।
  3. school_id ও school_name ঠিক রাখুন।
  4. questions array-এ exam questions যোগ করুন।

Supported types

mcq • fill_blank • true_false • short_answer

MCQ question-এ solution.enabled=true এবং solution.steps দিলে Exam interface-এ Solution button দেখা যাবে।
